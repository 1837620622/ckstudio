## 本地预览

```bash
cd ckstudio
python3 -m http.server 8765
# 或
npm run preview   # wrangler pages dev
```

## 部署（Cloudflare Pages）

```bash
npm install
npm run deploy    # wrangler pages deploy
```

或在 Cloudflare Dashboard 连接本仓库 `main` 分支自动构建。

- Node：`wrangler@^4.110`
- 输出目录：站点根目录（静态）
